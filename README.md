# PhonePe Transaction Analysis Dashboard | Power BI

## Project Overview
This project focuses on analyzing PhonePe transaction data using Microsoft Power BI. The dashboard provides insights into transaction performance, payment success rates, user demographics, service contributions, and usage patterns.

The goal is to transform transaction data into meaningful business insights through interactive visualizations and KPI monitoring.

## Objectives
- Analyze overall transaction volume and transaction value.
- Monitor payment success rates and transaction performance.
- Understand user distribution across age segments.
- Identify services contributing the highest transaction value.
- Compare weekday and weekend usage patterns.
- Track month-over-month (MoM) performance.

## Tools & Technologies
- **Power BI** – Dashboard development and data visualization
- **DAX** – Measures, calculated metrics, and KPI calculations
- **Power Query** – Data preparation and transformation

## Key Dashboard Metrics
- **Total Transactions:** 300K+
- **Total Transaction Value:** ₹3.47 Billion
- **Unique Users:** 108K+
- **Payment Success Rate:** 96%

## Key Insights
1. **Service Contribution:** Loans contribute approximately ₹2.5 billion, making them the largest contributor to transaction value.
2. **User Demographics:** Gen X (37.4%) and Millennials (37.3%) together account for approximately 74.7% of users.
3. **Monthly Growth:** Transaction value increased by 8.98% month-over-month.
4. **Usage Patterns:** Weekday transactions account for 71.6% of usage, while weekends account for 28.4%.
5. **Top Users:** Michael Smith recorded the highest transaction value among the top five users, at approximately ₹1.8 million.

## Dashboard Features
- Interactive month and payment-status filters
- KPI cards for transaction performance
- Monthly transaction trend analysis
- Age-segment contribution analysis
- Service-wise transaction value comparison
- Top 5 users by transaction value
- Weekday vs. weekend usage analysis
- Business insights section

## Project Outcome
This project demonstrates the use of Power BI and DAX to analyze transaction data, monitor key performance indicators, identify customer usage patterns, and communicate actionable business insights through an interactive dashboard.
